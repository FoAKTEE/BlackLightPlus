- Role: baseline (unpolarized RAPTOR method paper: geodesics, camera, invariant transfer, thermal synchrotron, OpenMP/OpenACC).
- Declarations (literature-grounded; line numbers in tex/RAPTOR_I_AA.tex):
  - Signature $(-,+,+,+)$, $G=c=1$ (l.285–288). Geodesic system $dx^\alpha/d\lambda=k^\alpha$, $dk^\alpha/d\lambda=-\Gamma^\alpha_{\mu\nu}k^\mu k^\nu$ (contravariant $k$) (l.322–326); $\Gamma$ from metric first derivatives (l.278–283).
  - Integrators: classical RK4 with 32 update coefficients (l.334–378); velocity Verlet (Dolence+2009) with optional re-evaluation of the predictor derivative (l.390–408). Convergence of $E,L,Q$ errors: 2nd order (Verlet), 4th order (RK4) in BL, MBL, KS, MKS (l.763–767, Fig. l.725–733). Performance table uses "RK2" (l.1611).
  - Adaptive step (Noble+2007, Dolence+2009): $d\lambda=1/(|d\lambda_{x^1}|^{-1}+|d\lambda_{x^2}|^{-1}+|d\lambda_{x^3}|^{-1})$, $d\lambda_{x^1}=\epsilon/(|k^r|+\delta)$, $d\lambda_{x^2}=\epsilon\,\min(x^\theta,1-x^\theta)/(|k^\theta|+\delta)$, $d\lambda_{x^3}=\epsilon/(|k^\phi|+\delta)$ (l.416–437). Values used: $\epsilon=0.001$ (geokerr comparison, l.815–816), $\epsilon=0.03$ (performance test, l.1610). Step size depends on geometry only, not optical depth (l.1089–1091).
  - Termination: optical-depth cutoff $\tau_{\rm cutoff}=\ln(1000)$ during backward integration (l.617–622, l.1044–1046, l.1063). Horizon/outer-radius stopping criteria are not stated in this paper (see [OPEN]).
  - Camera: distant observer at inclination $i$ ($90^\circ$ = equatorial), image vertical axis aligned with projected spin axis; impact parameters $\alpha$ (distance from rotation axis), $\beta$ (perpendicular) (l.441–451). Wave vector (Bardeen 1973): $L=-\alpha E\sqrt{1-\cos^2 i}$, $Q=E^2[\beta^2+\cos^2 i(\alpha^2-1)]$, $k_t=-E$, $k_\phi=L$, $k_\theta={\rm sign}(\beta)\sqrt{|Q-L^2\cot^2\theta+E^2\cos^2\theta|}$; $k^r$ from null condition; built in BL coordinates (l.452–467). Test setup: $r_{\rm camera}=10^4M$, $\alpha,\beta\in[-30,30]M$ (l.1056–1058).
  - Coordinates: BL, MBL, logarithmic KS, MKS (Gammie+2003) (l.485–490); BL→KS and KS→MKS transforms, MKS $\theta\to x^2$ inverted by Newton iteration (App. l.1443–1555).
  - Radiative transfer: invariant equation $d(I_\nu/\nu^3)/d\lambda=j_\nu/\nu^2-\nu\alpha_\nu(I_\nu/\nu^3)$ (l.519–524); fluid-frame frequency $\nu=-k^\alpha u_\alpha$ (l.535–538); $I_{\nu,\rm obs}=(I_\nu/\nu^3)\nu_{\rm obs}^3$ (l.550–553). Formal solution with $j$ constant per step (l.583–589). Adopted scheme: backward (camera→plasma) accumulation $d(I_{\nu,\rm obs}/\nu_{\rm obs}^3)/d\bar\lambda=(j_\nu/\nu^2)\,e^{-\tau_{\nu,\rm obs}}$, $\tau_{\nu,\rm obs}=\int_{\lambda_{\rm obs}}^{\lambda}\alpha_\nu\nu\,d\lambda'$, integrated simultaneously with the geodesic (l.600–666). No refraction, scattering, or polarization (l.500–506).
  - Emission: thermal Maxwell–Jüttner (l.949–953); Leung+2011 fit $j_\nu=\frac{\sqrt2\pi e^2 n_e\nu_s}{3cK_2(\Theta_e^{-1})}(X^{1/2}+2^{11/12}X^{1/6})^2\exp(-X^{1/3})$, $\nu_s=\frac29\frac{eB}{2\pi m_ec}\Theta_e^2\sin\theta$ (l.970–986); pitch angle via Dexter 2016 eq. 73 (l.991–992); test uses $K_2(1/\Theta_e)\approx2\Theta_e^2$ (l.995–998); absorption by Kirchhoff with $B_\nu$ (l.1014–1021).
  - Units: $\rho_0=\mathcal M/\mathcal L^3$, $B_0=c\sqrt{4\pi\rho_0}$, $\mathcal L=GM/c^2$, $\mathcal M$ free (l.1026–1031); $n_e=\rho\,\rho_0/(m_e+m_p)$ (l.1033–1036). Images in Jy pixel$^{-2}$ [sic] (l.691, l.1258).
  - Electron temperature: $T_p/T_e=R_{\rm low}/(1+\beta_p^2)+R_{\rm high}\beta_p^2/(1+\beta_p^2)$, $\beta_p=P_{\rm gas}/P_{\rm mag}$, $P_{\rm mag}=B^2/2$ (l.1176–1187); BHOSS comparison uses constant $T_p/T_e=3$ (l.1064).
  - Code comparison (BHAC snapshot, Sgr A*, 230 GHz, $i=90^\circ$): total-flux relative difference RAPTOR vs BHOSS 1.07% (128²) → 0.0063% (4096²) (l.1109–1135); abstract/text quote 0.06% at 4096² (l.1080–1082).
  - Slow light: time interpolation between GRMHD snapshots along the geodesic time coordinate (l.1142–1152); fast- vs slow-light light-curve difference < 5% (l.1295–1296); time alignment by empirical delay (l.1225–1230).
  - GPU/parallel: OpenMP (CPU) and OpenACC (CPU/GPU) (l.1560–1565); 10 CPU cores 10,707 geodesics/s, one GPU 104,900 geodesics/s (l.1070–1072, l.1592–1594); 2000² image 3 min 58 s (one CPU) vs 39 s (one GPU) (l.1622–1626); hardware i7-6950X, GTX 1080 (l.1643–1650); single precision in performance test (l.1607).
