# Admitted evidence — BlackLightPlus method paper

Paper `arxiv-2609.26298`. Each row is a quantitative or validation statement the manuscript may make,
with the number or tolerance exactly as it stands in the source. Status: *checked by test*
= asserted by `@test` in the suite; *measured benchmark* = recorded measurement on
2x NVIDIA A100 80 GB, 2x Intel Xeon Platinum 8360Y (144 cores), CUDA 13.2, Julia 1.12.6; warm (JIT excluded), best-of-N, legs run sequentially and exclusively (docs/src/benchmarks.md:3-8); *[OPEN]* = no supporting evidence in the repository. Benchmark rows (E1–E14) were measured on the code before the shared march and device pool (results/blp/multigpu/dag.md, MG07–MG13).
Every row is mirrored in the result ledger (`results/ledgers/result/paper_arxiv-2609.26298/`)
with a verification command (`results/blp/paper_arxiv-2609.26298/evidence/check_claim.py`) that fails if the cited text changes.
