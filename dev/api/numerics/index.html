BlackLightPlus.Numerics — Module
Numerics

Number-type-generic building blocks shared by every tier: CGS constants, units, ray-state accessors, interpolation stencils, exact integer-limb sums, the Philox counter RNG and the special functions of the synchrotron fits. Pure, allocation-free, isbits values only.

BlackLightPlus.Numerics.MCRng — Type
MCRng(key::NTuple{2,UInt32}, ctr::UInt32[, sid::NTuple{3,UInt32}])
MCRng(global_seed, stream_id[, ctr = 0])

Immutable isbits handle of one random stream. Draw n is philox4x32((n, sid...), key): key = (seed, identity word 1), the counter words 2–4 sid carry the rest of the stream identity (see MCStreamLayout), and ctr is the next draw index. The integer form starts the stream key = (seed, stream_id) (low 32 bits) with sid = 0.

BlackLightPlus.Numerics.MCStreamLayout — Type
MCStreamLayout(n_primary, track_max, max_layer)

Bit widths of the stream-identity fields for a run of n_primary primaries, at most track_max march steps (hence spawns) per photon and at most max_layer scattering layers: gid_bits for the primary index, event_bits per spawn ordinal, max_layer. Throws ArgumentError when the fields do not fit the 124 identity bits below the layer tag or max_layer ∉ 0:15.

RayState{T}

SVector{8,T} holding a ray state y = [x^μ; p_μ]: the contravariant position (t, x, y, z) in slots 1–4 and the covariant momentum (p_t, p_x, p_y, p_z) in slots 5–8. Read it with position and momentum, build it with raystate.

BlackLightPlus.Numerics.Units — Type
Units{T}

GRMHD code-unit to cgs conversions for a black hole of mass m_bh and a density mass scale mass_scale (both in g):

  • L_unit = G m_bh / c² (cm), T_unit = L_unit / c (s);
  • dens_unit = mass_scale / L_unit³ (g cm⁻³);
  • Ne_unit = dens_unit / (m_p + m_e) (cm⁻³);
  • B_unit = c √(4π dens_unit) (G);
  • e_unit = dens_unit c² (erg cm⁻³).

T is the promoted type of the six fields: a ForwardDiff.Dual mass scale makes every field a Dual, the mass-scale-independent L_unit and T_unit with zero partials.

BlackLightPlus.Numerics.corner_weights — Method
corner_weights(f, n) -> (i0, d)

Lower-corner index and blend fraction of the clamped trilinear stencil along one axis: f is the 0-based fractional cell coordinate, n the number of nodes. i0 = clamp(⌊f⌋, 0, n - 2) (so the upper corner i0 + 1 exists) and d = clamp(f - i0, 0, 1) (a one-sided blend outside the node range). The 1-based corner indices are i0 + 1 and i0 + 2.

source
BlackLightPlus.Numerics.cr_axis — Method
cr_axis(c, c0, dc, n) -> (w::SVector{4}, idx::NTuple{4,Int})

Catmull-Rom stencil along one axis of a uniform grid with first node c0, spacing dc and n nodes, at coordinate c: the weights cr_weights(t) and the four 1-based node indices, clamped to 1:n. The lower node is chosen from the derivative-free primal of the continuous index, so a Dual coordinate differentiates through the weights only.

BlackLightPlus.Numerics.cr_sample — Method
cr_sample(d, comp, ix, iy, iz, wx, wy, wz)

Tensor-product Catmull-Rom interpolation of field comp of the component-fastest array d[comp, i, j, k] over the 4×4×4 stencil with node indices ix, iy, iz and weights wx, wy, wz from cr_axis. The sums run x innermost, then y, then z, each from a zero of the weight type.

source
BlackLightPlus.Numerics.cr_weights — Method
cr_weights(t) -> SVector{4}

Catmull-Rom weights of the four nodes bracketing the fractional position t ∈ [0, 1] between the middle two: tangents are centred differences, so the interpolant is C¹ across every node and exact for quadratics. The weights sum to 1 and take the type of t (a Dual under AD).

BlackLightPlus.Numerics.harmonic_bridge — Method
harmonic_bridge(a, b, x) = (a^-x + b^-x)^(-1/x)

Harmonic-mean bridge of a low-frequency asymptote a and a high-frequency asymptote b with exponent x > 0 (blacklight HarmonicBridge); the smaller asymptote dominates. A zero or underflowed asymptote makes its power Inf, and the bridge returns 0, the limit of a vanishing asymptote.

hypergeometric_2f1(alpha, beta, gam, z) -> Float64

Gauss hypergeometric function ₂F₁(α, β; γ; z) for z < 0 (blacklight Hypergeometric): the Pfaff transform (1 - z)^(-α) ₂F₁(α, γ - β; γ; z/(z - 1)) with the series truncated after ten rising-factorial terms. Host only.

BlackLightPlus.Numerics.lerp8 — Method
lerp8(c, d1, d2, d3)

Trilinear blend of the eight corner values c = (c000, c100, c010, c110, c001, c101, c011, c111) (digit k is the corner's offset along axis k) with fractions d1, d2, d3 along axes 1, 2, 3. The corner values may be scalars or vectors. Association order, which fixes the bits:

c00 = c000 + (c100 - c000) * d1
c10 = c010 + (c110 - c010) * d1
c01 = c001 + (c101 - c001) * d1
c11 = c011 + (c111 - c011) * d1
c0  = c00 + (c10 - c00) * d2
c1  = c01 + (c11 - c01) * d2
return c0 + (c1 - c0) * d3

loglinear_at(x, table, x0, dx, n) -> value

Piecewise log-linear lookup: table[k] holds log f at ln x = x0 + (k-1) dx, k = 1:n; returns f(x) = exp of the linear interpolant in ln x, clamped to the first and last nodes. table may be any indexable (host or device array).

BlackLightPlus.Numerics.xsum_atomic_add! — Method
xsum_atomic_add!(acc, x::Float64, I...) -> nothing

xsum_add! for concurrent writers: at most three atomic Int64 additions into the limbs of cell acc[:, I...] (zero increments are skipped). Integer atomics commute, so the cell value does not depend on the arrival order. Runs on host arrays and, inside a kernel, on device arrays.

source
BlackLightPlus.Numerics.xsum_parts — Method
xsum_parts(x::Float64) -> (j, a, b, c)

Split x into the 1-based limb index j and the three signed increments a, b, c of limbs j, j+1, j+2. j == 0 for zero (nothing to add); j == XSUM_NSLOT for a non-finite value, with a == 1 its count. Pure integer arithmetic; device-safe.
