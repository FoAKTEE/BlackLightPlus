BlackLightPlus.Data — Module
Data

Containers and files: AthenaK snapshots as feature-fastest fluid blocks with eager locate tables, the .athdf and .bin readers, uniform grids, snapshot series with their two-frame windows, and the npy writer. Every grid-backed PlasmaProvider lives here; the sampling structs are isbits after Adapt.adapt.

BlackLightPlus.Data.AthenaKBin — Type
AthenaKBin

An AthenaK .bin AMR dump. Fields: n_mb blocks of nx1 × nx2 × nx3 cells; var_names; per-block AMR level and face bounds x1min, x1max, x2min, x2max, x3min, x3max; data, the (nx1, nx2, nx3, n_vars, n_mb) Float32 cell values (i fastest, as on disk); time, the dump time (code units).

BlackLightPlus.Data.AthenaKSnapshot — Type
AthenaKSnapshot <: GridProvider
AthenaKSnapshot(filename; gamma = nothing)
AthenaKSnapshot(data, lo, hi, x_left, dx, levels, logical_locations;
                names = PRIM_NAMES, time = 0.0)

One AthenaK snapshot on the host. Fields: blocks, the FluidBlocks sampled by primitives; levels, the AMR level of each block; logical_locations, the (3, nmb) logical index of each block at its level; names, the primitive names in storage order; time, the simulation time of the dump (code units; NaN when an .athdf file carries no Time attribute).

The file constructor reads uov, B, the cell centres x1v, x2v, x3v, the faces x1f, x2f, x3f, Levels, LogicalLocations and VariableNames. Two uov layouts are accepted: dens velx vely velz eint (stored as is) and dens velx vely velz press [temperature] (the mhd_w_bcc output with use_e = true), which needs gamma: eint = press/(gamma - 1) is computed in Float64 and rounded once to Float32, the temperature columns are dropped and non-finite cells are zeroed with one warning. Any other layout is an error. The block geometry is lo = x?f[1], hi = x?f[end], x_left = x?v[1], dx = x?v[2] - x?v[1] per block.

The array constructor takes data as (8, ni, nj, nk, nmb) in PRIM_NAMES order, lo, hi, x_left, dx as (3, nmb) matrices (or vectors of SVector{3}), and levels, logical_locations as above; arrays already of type Array{Float32,5} and Matrix{Float64} are stored without a copy. Both constructors build the locate strategy eagerly with build_locate. primitives(snap, x) and domain_radius(snap) are those of snap.blocks; Adapt.adapt(to, snap) is Adapt.adapt(to, snap.blocks).

BlackLightPlus.Data.BlockScan — Type
BlockScan()

Linear scan over the block bounds: a point belongs to block m when lo[a, m] < x_a ≤ hi[a, m] on every axis, and the last such block in storage order wins (AthenaK stores finer blocks later). O(nmb) per point; valid for any mesh and on any device.

BlackLightPlus.Data.FluidBlocks — Type
FluidBlocks{A5,A2,L} <: GridProvider

The fluid of an AthenaK snapshot as a sampling struct. Fields:

  • data: (8, ni, nj, nk, nmb) Float32 cell-centred primitives, feature fastest, in the order PRIM_NAMES = (dens, velx, vely, velz, eint, bcc1, bcc2, bcc3): rest-mass density, normal-frame velocity W v^i, internal energy density, cell-centred field; code units.
  • x_left, dx: (3, nmb) Float64 first cell centre and cell width of each block.
  • lo, hi: (3, nmb) Float64 face bounds of each block.
  • ni, nj, nk: cells per block along each axis; nmb: number of blocks.
  • locate: the strategy that finds a point's block, a LeafTable, LevelHash or BlockScan.

primitives(b, x) is the clamped trilinear sample in the owning block, in Float64. Adapt.adapt(to, b) moves every array and turns a LevelHash into a BlockScan; the result is isbits on a device. Built by the AthenaKSnapshot constructors.

BlackLightPlus.Data.FrameWindow — Type
FrameWindow{P} <: GridProvider
FrameWindow(a::P, b::P, t_a, t_b; t_obs = <upper end>)

Two frames of one provider type P on the same mesh, a at coordinate time t_a and b at t_b, blended at the emission time t_obs + X⁰ of each sample. Fields: a, b, t_a, inv_dt = 1/(t_b - t_a) (0 when t_b is not finite or not after t_a, the fast-light limit) and t_obs, the observation epoch at the camera, by default the upper end t_a + 1/inv_dt (t_a when inv_dt = 0). isbits after Adapt.adapt when P is.

primitives(win, x) forms w = clamp((t_obs - t_a + X⁰) inv_dt, 0, 1) with X⁰ = x[1] and returns frame b's sample when w == 1, frame a's when w == 0, and blend of the two samples otherwise.

BlackLightPlus.Data.LeafTable — Type
LeafTable{A<:AbstractArray{Int32,3}}

Dense finest-block index grid: leaf[i, j, k] is the owning block (1-based, 0 for vacuum) of finest-block cell (i, j, k), whose low corner is (x1min + (i-1)/inv_fdx1, …). Fields: leaf, the mesh bounding box x1min … x3max, the inverse finest-block widths inv_fdx1 … inv_fdx3, the grid size N1, N2, N3 and the block count nmb. A point is assigned to the cell ⌊(x - x1min) inv_fdx1⌋ (and likewise per axis), so a shared face belongs to the block on its high side; outside [0, N) on any axis the point is vacuum. Built by leaf_table; isbits after Adapt.adapt.

source
BlackLightPlus.Data.LevelHash — Type
LevelHash

Per-level hash of the leaf blocks, for meshes without a dense leaf table (over 8 000 000 finest-block cells, or not aligned to the finest grid): dict[(L, lx1, lx2, lx3)] is the block at level L and logical location (lx1, lx2, lx3); levels lists the levels present in ascending order; x1min … x3max is the mesh bounding box and inv_w0 the inverse root-block width per axis. A point inside the half-open box [min, max) is located by probing the levels coarse to fine at logical index ⌊(x - xmin) 2^L / w0⌋; the first hit wins. Host only: Adapt.adapt returns BlockScan(). Built by level_hash.

BlackLightPlus.Data.SeriesProvider — Type
SeriesProvider <: GridProvider

A host provider that samples series at any emission time: primitives(p, x) finds the bracket of t_obs + X⁰ with bracketing_pair, returns the lower frame's sample when w == 0, the upper frame's when the two frames are the same object or w == 1, and blend of the two samples otherwise. Frames are fetched with get_frame, so a path-backed series may load and evict under its lock; not for devices.

BlackLightPlus.Data.SnapshotSeries — Type
SnapshotSeries
SnapshotSeries(paths, times; maxslots = 2, t_obs = times[end])

Snapshots at ascending coordinate times times (code units), either loaded from the .athdf files paths on first use and kept in a least-recently-used cache of maxslots ≥ 2 frames, or held in memory (built by synthetic_series). t_obs is the observation epoch at the camera and must lie in [times[1], times[end]]. A frame loaded while a frame of the same mesh is resident shares that frame's locate strategy and geometry arrays. Loads, cache updates and evictions of a path-backed series hold the series lock; a held-in-memory series is read only. Fields: times, paths, frames (index → snapshot), order (least recent first), maxslots, t_obs, lk.

BlackLightPlus.Data.UniformGrid — Type
UniformGrid{A4} <: GridProvider
UniformGrid(data, box_half)

The fluid on the n³ nodes of the box [-box_half, box_half]³. Fields: data, the (8, n, n, n) Float32 primitives in PRIM_NAMES order (feature fastest), node (i, j, k) at (xo + (i-1)/inv_dx, xo + (j-1)/inv_dx, xo + (k-1)/inv_dx); n; xo = -box_half; inv_dx = (n - 1)/(2 box_half); box_half. Nodes outside every block hold zeros. The two-argument constructor derives n, xo and inv_dx from data and box_half. Built from a provider by resample; isbits after Adapt.adapt.

BlackLightPlus.Data.advance — Method
advance(win::FrameWindow, series, ia; t_obs = <upper end>) -> FrameWindow

The window over frames ia and ia + 1, where win.b is frame ia: win.b becomes the lower frame unchanged (same object) and only the upper frame is built, as the frame's blocks or as a resample with the geometry of win.b. BlackLightPlus.Data.athenak_bin_snapshot — Method
athenak_bin_snapshot(binfile; gamma) -> AthenaKSnapshot

The GRMHD fluid of an AthenaK .bin dump (the mhd_w_bcc output group) as a snapshot. dens, velx, vely, velz, bcc1, bcc2, bcc3 are copied bit for bit; eint = press/(gamma - 1) is computed in Float64 and rounded once to Float32; a temperature column is dropped; non-finite cells are zeroed with one warning. Block geometry: dx = (max - min)/n, x_left = min + dx/2 per axis; logical locations are (min - domain_min)/width, which must be integral within 1e-6 per block and axis.

BlackLightPlus.Data.block_sample — Method
block_sample(b::FluidBlocks, mb, x, y, z) -> SVector{8,Float64}

Clamped trilinear sample of the eight primitives inside block mb at (x, y, z): the fractional cell index is (x - x_left)/dx per axis (a division, so dx is never inverted), the lower corner and the blend fraction are clamped by corner_weights, and the corners are blended by lerp8 along i, then j, then k.

BlackLightPlus.Data.bracketing_pair — Method
bracketing_pair(series, t) -> (ia, w)

The frame bracket of coordinate time t: the lower frame ia ∈ 1:N-1 (the last with times[ia] ≤ t) and the weight w = (t - t_a)/(t_b - t_a) ∈ [0, 1] of the upper frame ia + 1. Clamped at the ends: t ≤ times[1] gives (1, 0.0), t ≥ times[N] gives (N - 1, 1.0); a one-frame series gives (1, 0.0).

BlackLightPlus.Data.build_int_jnu_table — Method
build_int_jnu_table(zone, wgt; refine = INT_JNU_REFINE) -> IntJnuTable

Tabulated ∫j_ν dΩ of zone on the refine-fold refinement of the nodes of wgt (every weight node is a table node). Frame ia. A held-in-memory series returns it without changing any state. BlackLightPlus.Data.grid_sample — Method
grid_sample(g::UniformGrid, x, y, z) -> (p::SVector{8,Float64}, inside::Bool)

Trilinear sample of the eight primitives at (x, y, z). The fractional node index is f = (x - xo) * inv_dx per axis; a point with any f < 0 or f > n - 1 is outside (zeros, false). Inside, the lower node is min(⌊f⌋, n - 2) and the fraction f - ⌊f⌋ is not clamped; the corners are blended by lerp8 along i, j, k.

BlackLightPlus.Data.leaf_table — Method
leaf_table(lo, hi, levels, logical_locations) -> Union{LeafTable, Nothing}

The dense finest-block index grid of a mesh with (3, nmb) face bounds lo, hi, per-block AMR levels and (3, nmb) logical_locations. The finest width per axis is the smallest block width; a level-L block at logical lx covers finest cells [lx 2^s, (lx+1) 2^s) with s = Lmax - L. Blocks are written in storage order, so where two overlap the later one owns the cell. Returns nothing for an empty or degenerate mesh, a grid over 8 000 000 cells, or blocks that fall outside the grid (a mesh not aligned to its finest level from the domain origin).

The per-level hash of a mesh (arguments as in leaf_table). The root-block width w0 is block 1's width times 2^level; returns nothing for an empty mesh or when any block's width times 2^level differs from w0 by more than 1e-9 |w0| on an axis.

The block (1-based) that owns the Cartesian Kerr–Schild point (x, y, z), or 0 when no block does, under strategy (default b.locate). The strategies agree everywhere off block faces; on a face each keeps its own rule (see LeafTable, LevelHash, BlockScan).

BlackLightPlus.Data.read_athenak_bin — Method
read_athenak_bin(filename) -> AthenaKBin

Read an "Athena binary output version=1.1" dump: an ASCII header ending in header offset=<H>, an H-byte parameter dump, then per block Int32[10] = (ois, oie, ojs, oje, oks, oke, lx1, lx2, lx3, level), Real[6] face bounds (Real has the header's size of location, 8 or 4 bytes) and Float32[n_vars nx3 nx2 nx1] cell data (i fastest, then j, k, variable). Errors on another version, a variable size other than 4 bytes, or a data section that is not a whole number of blocks.

BlackLightPlus.Data.resample — Method
resample(p::GridProvider, box_half, n) -> UniformGrid

Sample the host provider p (an AthenaKSnapshot or FluidBlocks) at the n³ nodes -box_half + (i - 1) dx, dx = 2 box_half/(n - 1), of the box [-box_half, box_half]³ at time 0, rounding each primitive to Float32; nodes outside the provider's domain hold zeros. Threaded over z slabs.

source
BlackLightPlus.Data.resample_z4c_adm — Method
resample_z4c_adm(s::AthenaKBin, half, n; alpha_min = 0.15) -> ADMGrid

The ADM fields of a Z4c dump resampled onto the uniform n³ node box [-half, half]³ (range(-half, half; length = n) per axis) as an ADMGrid with capture lapse alpha_min. Each node locates its block once and samples the eleven variables with sample_var's stencil: α, β^i directly, γ_ij = ψ⁴ g̃_ij with ψ⁴ = max(χ, 1e-12)^(4/(-4)). Nodes off the mesh, or where χ is NaN, get Minkowski values (α = 1, β = 0, γ = δ). Threaded over z slabs.

BlackLightPlus.Data.sample_var — Method
sample_var(s::AthenaKBin, v, x, y, z) -> Float64

Trilinear sample of variable column v (1-based) at (x, y, z), or NaN off the mesh. The owning block is the finest whose closed face box contains the point (the first in storage order among equals); cell centres sit at x1min + (i - ½) dx1, the lower corner is clamped to 1:nx-1 and the fraction to [0, 1], and each axis blends as a (1 - t) + b t.

BlackLightPlus.Data.write_npy — Method
write_npy(path, a::AbstractMatrix{Float64}) -> path

Write a to path as a NumPy .npy file, format version 1.0: the magic string, the header {'descr': '<f8', 'fortran_order': False, 'shape': (m, n), } padded with spaces and a newline to a multiple of 64 bytes, then the little-endian Float64 values in C (row-major) order, so numpy.load(path)[i-1, j-1] == a[i, j].

BlackLightPlus.Matter.domain_radius — Method
domain_radius(b::FluidBlocks) -> Float64

Radius of the sphere about the origin that circumscribes the located domain; every point beyond it is vacuum. With a LeafTable the box is the leaf grid, [x1min, x1min + N1/inv_fdx1] × …; with a LevelHash or BlockScan it is the bounding box of the block faces.
