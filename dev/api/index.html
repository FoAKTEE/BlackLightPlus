API Overview

BlackLightPlus — Module
BlackLightPlus

General-relativistic ray tracing, polarized radiative transfer and Monte Carlo Comptonization in Julia. Conventions: signature (−,+,+,+); G = c = M = 1; Cartesian Kerr–Schild coordinates; ray state y = [x^μ; p_μ] with covariant momentum; Lorentz-invariant coefficients (j/ν², αν, ρν); Stokes transfer in a parallel-transported camera frame.

Three tiers, included in dependency order: physics (Numerics, Spacetime, Matter, Transfer, MonteCarlo), infrastructure (Data, Execution) and pipeline (Plans, Analysis, Products). A product runs on the CPU or on GPUs according to its backend keyword; see backend! and BLP_BACKEND.

source

What is public

The public API is what BlackLightPlus exports: the configuration records and prepare, the spacetimes, the matter providers, the transfer modes, the executors and the backend switch, the products, their result types and the analysis utilities. Every exported name has a docstring and the documentation build checks that each is on one of the pages below (checkdocs = :exports). The structure gate test/structure.jl checks the same for every submodule's exports and holds the top-level API at its budget.

A name with a leading underscore is private to its module and is never referenced from another module or from the tests. The remaining non-exported names are the submodule interfaces: stable within a minor version, documented on the same pages under "Internal", and reached as BlackLightPlus.Spacetime.trace_geodesic or with using BlackLightPlus.Spacetime: trace_geodesic.

Conventions

These hold throughout the API and are not repeated in every docstring:

  • Metric signature $(-,+,+,+)$; geometrized units $G = c = M = 1$.
  • Cartesian Kerr–Schild coordinates $x^\mu = (t, x, y, z)$.
  • The ray state is the 8-vector $y = [x^\mu;\, p_\mu]$ with covariant momentum, $p = -k$ for the received wave covector $k$ ($p_t = +1$), integrated to increasing affine parameter from the camera into the past.
  • Transfer coefficients are Lorentz invariant: $j_\nu/\nu^2$, $\alpha_\nu \nu$, $\rho_\nu \nu$; the invariant intensity is $I_\nu/\nu^3$.
  • Images are laid out [iβ, iα]; Stokes parameters follow IEEE/IAU. The full table is in Method.
