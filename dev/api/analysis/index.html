Analysis module

BlackLightPlus.Analysis — Module
Analysis

Image-plane analysis: the block refinement indicators of adaptive rendering, the lensing-band geometry of photon-ring imaging on the Bardeen screen (apparent horizon, band edges, band grids, polygon area and membership), and interferometric visibility amplitudes (Radon cut, Tukey window, |V| against baseline in Gλ). Host code; the screen unit is M and image angles are in μas.

BlackLightPlus.Analysis.MUAS_TO_RAD — Constant

One microarcsecond in radians, π / 648000 × 10⁻⁶.

BlackLightPlus.Analysis.AbsoluteGradient — Type
AbsoluteGradient(cut; count = 5)

The value-based absolute-gradient indicator: fires when at least count pixels of the block have an absolute gradient above cut.

At pixel (i, j), qx = (I[i,j+1] − I[i,j−1]) / 2 in the interior and the one-sided I[i,2] − I[i,1], I[i,nj] − I[i,nj−1] at the edges; qy is the same along i, and q = hypot(qx, qy) is in intensity units per pixel step. Pixels are scanned with i outer and j inner; a non-finite q is skipped, and after every finite one the count of q > cut is compared with count, so a count ≤ 0 fires at the first finite pixel. Because the cut is absolute, a smooth feature falls below it under refinement while an unresolved edge stays above it; it does not saturate on dim backgrounds as the relative indicators do. The block needs at least two pixels along each side.

Fields: cut::Float64, count::Int.

BlackLightPlus.Analysis.RefinementIndicator — Type
RefinementIndicator

Supertype of the built-in block refinement indicators: RelativeGradient, RelativeLaplacian, AbsoluteGradient and the disjunction AnyOf. An indicator decides through needs_refinement; wherever an indicator is accepted, a callable f(I::AbstractMatrix) -> Bool is accepted too.

BlackLightPlus.Analysis.RelativeGradient — Type
RelativeGradient(cut = 0.15; frac = 0.03)

The relative-gradient indicator: fires when more than the fraction frac of a block's pixels have a relative gradient above cut.

At pixel (i, j) of an ni × nj block I the difference along j is the central difference over the stencil-weighted sum, qx = 2 (I[i,j+1] − I[i,j−1]) / (I[i,j−1] + 2 I[i,j] + I[i,j+1]), and two-point at the block edges, qx = 2 (I[i,2] − I[i,1]) / (I[i,1] + I[i,2]) at j = 1 and qx = 2 (I[i,nj] − I[i,nj−1]) / (I[i,nj−1] + I[i,nj]) at j = nj; qy is the same along i, and q = hypot(qx, qy) is dimensionless, per pixel step. A pixel with a non-finite q (zero denominator, NaN or infinite intensity) is not counted. With nch the counted pixels and nex those with q > cut, the indicator fires when nch > 0 and nex / nch > frac. A negative or NaN frac disables it. The block needs at least two pixels along each side.

Fields: cut, frac (Float64).

BlackLightPlus.Analysis.RelativeLaplacian — Type
RelativeLaplacian(cut = 1.0; frac = 0.03)

The relative-Laplacian indicator: fires when more than the fraction frac of a block's interior pixels have a relative Laplacian above cut.

At each interior pixel (2 ≤ i ≤ ni − 1, 2 ≤ j ≤ nj − 1) the five-point Laplacian L = I[i,j−1] + I[i,j+1] + I[i−1,j] + I[i+1,j] − 4 I[i,j] is divided by the local weighted mean m = (I[i,j−1] + I[i,j+1] + I[i−1,j] + I[i+1,j] + 4 I[i,j]) / 8, giving q = |L| / m, dimensionless. Counting, threshold and disabling are those of RelativeGradient; a block without interior pixels never fires.

Fields: cut, frac (Float64).

BlackLightPlus.Analysis.apparent_horizon — Method
apparent_horizon(a, θo; n = 100, ro = 1e5) -> (α::Vector, β::Vector)

The apparent horizon on the Bardeen screen (M = 1) for spin a and observer inclination θo (rad): the image of the event horizon, the inner edge of the direct image (lensing band n = 0). Each point of critical_curve(a, θo; n) is scaled by the s ∈ (0.05, 0.999) at which the ray from the observer at radius ro reaches the horizon exactly (AART ApparentBH; P1 Eqs. 8a, 20), with m = 1 angular turning point on the upper half (β ≥ 0) and m = 0 on the lower; a point whose root is not bracketed takes s = 0.99. For θo > π/2 the curve is that of π − θo with β → −β. Empty when the critical curve is.

References

Gralla & Lupsasca (2020a), Eqs. 8a, 20; Cárdenas-Avendaño, Lupsasca & Zhu (2023).

BlackLightPlus.Analysis.band_grid — Method
band_grid(inner, outer; dx = 0.02, box = nothing) -> (grid, mask, N)

A Cartesian grid on the Bardeen screen and the mask of its points inside the band between the polygons inner and outer (N × 2 vertex matrices, as returned by lensing_band); AART grid_mask. The axis is range(-lim, lim; length = N) with lim = box, or maximum(abs, outer) + 5dx when box is nothing, and N = 2 round(Int, lim / dx). grid is the N² × 2 matrix of points (α, β) with α fastest. mask[k] holds when the point is inside outer and, if inner has at least three vertices, not inside inner, both by in_polygon. Returned as a NamedTuple.

BlackLightPlus.Analysis.in_polygon — Method
in_polygon(px, py, xs, ys) -> Bool

Whether the point (px, py) lies inside the closed polygon (xs, ys) (last vertex joined to the first), by a nonzero winding number. The edge from vertex k to k + 1 adds +1 when it crosses the line y = py upward (ys[k] ≤ py < ys[k+1]) with the point strictly to its left, and −1 when it crosses downward (ys[k+1] ≤ py < ys[k]) with the point strictly to its right. The half-open rule decides points on the horizontal line of a vertex; an edge through the point itself contributes nothing, so a point on the boundary is inside or outside according to the remaining edges.

BlackLightPlus.Analysis.lensing_band — Method
lensing_band(a, θo, n; npts = 100, box = 25.0) -> (inner, outer)

Inner and outer edges of lensing band n on the Bardeen screen (M = 1) for spin a and observer inclination θo (rad), each an N × 2 matrix of vertices (α, β). Band n = 0 (the direct image) is bounded inside by apparent_horizon(a, θo; n = npts) and outside by the square of half-width box. A band n ≥ 1 is a thin annulus about the critical curve: each point of critical_curve(a, θo; n = npts) is scaled inward to the case-III root and outward to the case-II root of the AART nlayers condition (P2 Eqs. A10, A11; P3), found by bisection; an unbracketed root falls back to s = 0.999 (inner) or 1.001 (outer) with a warning. For θo > π/2 the edges are those of π − θo with β → −β, so (α, β) lies in band n at θo exactly when (α, −β) does at π − θo.

References

Gralla & Lupsasca (2020b), Eqs. A10, A11; Cárdenas-Avendaño, Lupsasca & Zhu (2023).

BlackLightPlus.Analysis.needs_refinement — Method
needs_refinement(indicator, I::AbstractMatrix) -> Bool

Whether the block whose pixel intensities are I (I[i, j], pixel i along the first image axis and j along the second, in any consistent intensity unit) is refined under indicator: a RefinementIndicator, or any callable, which is called as indicator(I) and must return a Bool. The built-in indicators are pure functions of I, so blocks may be tested concurrently and in any order.

BlackLightPlus.Analysis.polygon_area — Method
polygon_area(xs, ys) -> area
polygon_area(poly::AbstractMatrix) -> area

Area enclosed by the closed polygon with vertices (xs[k], ys[k]), the last joined to the first, by the shoelace formula |Σₖ (xₖ yₖ₊₁ − xₖ₊₁ yₖ)| / 2: the enclosed area of a simple loop of either orientation, the absolute net signed area of a self-intersecting one. The matrix form takes the vertices as rows (x, y). Units are those of the coordinates squared (M² on the Bardeen screen).

BlackLightPlus.Analysis.radon_cut — Method
radon_cut(img, angle_deg; fov_muas) -> (projection, s_axis)

Parallel-beam Radon projection of the square image img[iβ, iα] (rows β, columns α, N × N pixels over the full field of view fov_muas in μas) onto the axis at angle_deg degrees from +α toward +β. With c = (N + 1)/2, the pixel (iβ, iα) sits at offsets (x, y) = (iα − c, iβ − c) pixels and projects to t = x cos θ + y sin θ; its value is split linearly between bins ⌊t + c⌋ and ⌊t + c⌋ + 1, and the parts that fall outside 1:N are dropped. Exact for axis-aligned cuts, first order at oblique angles. Returns the length-N projection (sum of pixel values per bin) and its offset axis s_axis[k] = (k − c) fov_muas / N in μas.

BlackLightPlus.Analysis.refinement_indicator — Method
refinement_indicator(; rel_grad_cut = 0.15, rel_grad_frac = 0.03, rel_lapl_cut = 1.0,
                     rel_lapl_frac = 0.03, abs_grad_cut = nothing, abs_grad_count = 5)
    -> RefinementIndicator

The indicator named by a keyword set: AbsoluteGradient(abs_grad_cut; count = abs_grad_count) when abs_grad_cut is a number, the relative pair then being unused; otherwise AnyOf(RelativeGradient(rel_grad_cut; frac = rel_grad_frac), RelativeLaplacian(rel_lapl_cut; frac = rel_lapl_frac)), where a negative fraction switches its member off. Without keywords it is the default indicator of adaptive rendering.

BlackLightPlus.Analysis.tukey_window — Function
tukey_window(n, α = 0.5) -> Vector{Float64}

The tapered-cosine (Tukey) window of length n: one in the centre, with cosine tapers w[k+1] = (1 + cos(π (−1 + 2k / (α (n − 1))))) / 2 for k = 0, …, ⌊α (n − 1) / 2⌋, mirrored onto the other end. α ≤ 0 gives the rectangular window, α ≥ 1 the Hann window; n = 1 gives [1.0]. The convention of scipy.signal.windows.tukey.

BlackLightPlus.Analysis.visamp — Method
visamp(img; angles = (0.0, 90.0), fov_muas, pad = 16, maxbaseline = Inf,
       window = :tukey) -> Vector{NamedTuple}

Normalised visibility amplitude of the square image img[iβ, iα] (field of view fov_muas in μas) along each baseline position angle in angles (degrees from +α toward +β). Per angle: the radon_cut, times tukey_window(N, 0.5) when window === :tukey (else no window), zero-padded to pad × N samples, FFT, |V|. Baselines are the non-negative FFT frequencies below maxbaseline, converted from cycles per μas to Gλ (10⁹ wavelengths, i.e. cycles per radian / 10⁹); the amplitude is divided by its value at the first kept baseline (zero) when that is positive. Returns one (angle, baselines, amplitude) per angle, angle as Float64. A ring of angular diameter d μas shows minima spaced by ≈ 1 / (d MUAS_TO_RAD 10⁹) Gλ.

References

Johnson et al. (2020), Sci. Adv. 6, eaaz1310; Cárdenas-Avendaño, Lupsasca & Zhu (2023).

BlackLightPlus.Analysis.visamp_minima — Method
visamp_minima(baselines, amplitude; skip = 1, bl_min = 0.0) -> Vector{Float64}

Baselines (in the unit of baselines, Gλ for visamp) of the local minima of the amplitude curve: interior points i with amplitude[i] < amplitude[i-1], amplitude[i] ≤ amplitude[i+1] and baselines[i] > bl_min, in order, without the first skip of them (the roll-off of the zero-baseline lobe). When at most skip minima are found they are all returned. Successive spacings measure the ring diameter.
